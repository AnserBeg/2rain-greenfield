## Outcome

This packet removes four small but live sources of false or flaky results and
records the repository shape that the implementation actually uses:

1. ADR-0007's append-only inventory-owner exemption follows the real
   `packages/domain/src/inventory/` module path. It does not exempt sibling
   domains, mutable movement operations, or writable stock/balance state.
2. Party's archive/create race records the racing role ID and, when role create
   wins, archives that role before later global list-count assertions. Both
   permitted race outcomes now lead to the same measured fixture state; the
   exact count assertions remain unchanged.
3. Ephemeral PostgreSQL waits until a real host SQL connection succeeds or the
   container actually stops. It no longer rejects a valid slow startup at 30
   seconds or kills a Docker command at 45 seconds. Docker auto-removal remains
   enabled. Inspection, diagnostics, and `finally` cleanup tolerate only
   Docker's exact missing-container result; every other Docker failure remains
   visible.
4. `@north-star/postgres-provider` no longer advertises its migration runner as
   the package root. Its named public subpaths are unchanged, and an
   architecture control rejects both a reintroduced `"."` export and any bare
   package consumer.
