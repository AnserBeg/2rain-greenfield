## Outcome

U0 freezes the existing literal-colour debt under `apps/web/src` without
changing any product styling. The checked-in baseline is **69 occurrences**.
All 69 were observed in `apps/web/src/surface-runtime.ts`; their current
compression onto four source lines is not part of the contract.

The counting unit is an **occurrence**, not a line. Each literal is one future
U2 token-migration obligation, while formatting can combine or split lines
without changing that work. Counting lines would also let another literal be
added to an already-counted line without moving the baseline.

The observer recursively reads the real files below `apps/web/src` and counts
standalone CSS hex-colour forms with 3, 4, 6, or 8 hexadecimal digits. The
ratchet requires exact equality. An increase is
`WEB_SURFACE_HEX_LITERAL_INCREASE`; an unrecorded decrease is
`WEB_SURFACE_HEX_LITERAL_UNRECORDED_DECREASE`. A deliberate burn-down therefore
moves the baseline in the same commit rather than disappearing unnoticed.

No file below `apps/web/src` changed in this packet. U2 still owns token
extraction, styling, dark mode, and the visual-system migration.

## Controls

`test/unit/web-surface-hex-literal-ratchet.test.ts` carries three observations:

1. the real web source has at least one source file and exactly the reviewed
   occurrence count;
2. a synthetic observation at `baseline + 1` returns the increase violation;
3. a synthetic observation at `baseline - 1` returns the unrecorded-decrease
   violation, pinning exact-count rather than ceiling behavior.

The new test is registered in every explicit executed-file inventory:

- `package.json` under `test:unit`;
- `test/architecture/repository-hygiene.test.ts` under the unit suite;
- `test/helpers/reachability-producers.ts` under the unit producer.

## Gate evidence

The direct three-control run, `typecheck`, `test:architecture`, and the full
matrix results are reported against the frozen candidate in the writer handoff;
a commit cannot contain its own SHA.

For a user-testable checkpoint under ten minutes, run:

```bash
node --import tsx --test test/unit/web-surface-hex-literal-ratchet.test.ts
corepack pnpm test:architecture
```

Expect three ratchet controls to pass, including the `baseline + 1` red arm,
and the architecture suite to accept the three matching registrations. Adding
one hex colour below `apps/web/src` without moving the baseline makes the first
control fail.
