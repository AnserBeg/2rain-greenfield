# ADR-0088. Build reports from governed record queries

**Proposed for Fable’s design read · 2026-11-20.** An office worker can open **Customize → Add report** on Invoices or on a record type their company built, choose what one row represents, group it and publish the report. A colleague can run it with their own grants and export exactly the totals they can see. The rentals ERP inventory (§C) supplies the use cases for datasets, approved measures, charts and CSV. Receivables aging and customer statements in parked PR #34 are downstream examples. [Packet and walkthrough](../execution/packets/REPORTS-1.md) · [Plan §§6.6, 8.5–8.6, 9.2, 10.2, 12.2 and 12.8](../greenfield-north-star-erp-platform-plan.md)

## What a report declares

| Choice in Customize | What the compiler must resolve from the active package |
| --- | --- |
| Dataset | Owning record type and registered query ID, source contract, one business fact per row (grain), stable identity, archive rule, ownership, temporal basis and freshness. A source can be a generated collection or a first-party read model with verified lineage. |
| Filter | Declared, selectable operands and typed parameters. Start with equality, membership from a bounded choice list, and half-open date ranges. Combine them by AND with the source restrictions. The author can expose parameter inputs and narrower saved presets. |
| Group | Ordered, reportable dimension IDs. Group choices and references by stable value ID, with authorized labels for display. An optional absent dimension has a labelled **Unspecified** group. Calendar and age dimensions declare their source and boundary rules. |
| Measure | Stable measure ID, label, source query and grain, operator, operand selections, unit/currency binding, absence and result contract, permitted sinks and lineage to stored facts. The compiler derives types and verifies the whole dependency set, including derived inputs. |
| Presentation | Title, ordered group and measure columns, initial sort, eligible outputs and drill-through to a governed List with the same predicates. A chart binds axes/series to typed result columns. Customer data can configure only platform-owned components. |

The existing reporting projection lists reportable fields and their lineage. The current Q1 aggregate is a scalar required sum. Extend the **existing** reporting, query, policy, surface, agent and verification projections with an optional versioned report definition and a registered grouped Q1 query. The gateway returns a distinct grouped result with typed keys, cells, per-partition totals, coverage, read instant and continuation. A group has no business-record ID or revision. The scalar contract and row List keep their existing envelopes. Feed the compiler’s closed lowering plan to the provider using bound parameter values and catalog-resolved identifiers. Refuse fields with an unsupported lowering, classification, display-only sink or unavailable index during preview. [ADR-0022](ADR-0022-query-level-aggregate-contract.md) · [ADR-0074](ADR-0074-formula-rule-and-workflow-projection-admission.md) · [ADR-0077](ADR-0077-exact-decimal-calculated-display.md)

An approved measure can be reused by stable ID and contract revision. A business author can propose one from the same finite operators and reportable operands, preview its definition and trial it on authorized data. The publish diff shows the basis (for example, invoiced rent versus cash collected), grain, date, units, exclusions and consuming reports/cards. Human approval covers the exact candidate. Editing the measure produces a new revision and requires reverification of its consumers. Discovery offers only measures in the serving release whose dependencies and purpose the person may read. A prose request or display format cannot declare that a number is money. An existing invoice amount needs an authoritative amount/currency binding in its source contract. A tenant-built Inspection can start with count by outcome using its existing choice field.

## What contributes once

Slice 1 uses one source record per fact. A later report may traverse declared to-one links. A line report explicitly chooses **one row per line** and a declared, scoped parent relation. Verify target uniqueness, key types, cardinality, source permissions and owner scope at each hop. Collect authorization even for a field used only in a filter. An optional missing relation yields absence under its declared semantics. An unreadable target supplies neither a value nor evidence of its existence. Refuse a join if its scoped semantics cannot be proved. A parent amount can contribute only at parent grain. Refuse counting a parent sum once per line, sibling line joins, inferred text matches and other paths that multiply the measured fact. Distinct count of a declared parent identity at line grain is an explicit measure. A domain balance comes from its governed read model. [Query and authorization guarantees](ADR-0071-read-decisions-are-live-per-request-writes-per-call.md)

| Operator | Group and total semantics |
| --- | --- |
| Count | Count rows at the declared grain. Empty input gives zero. |
| Sum | Sum a required exact decimal, quantity or governed amount. Preserve scale, unit and currency. A known empty partition has typed zero. An empty result invents no currency. |
| Min / max | Take the least/greatest present comparable typed value. Return tagged absence when there is none. |
| Average | Carry the exact sum and count of present numeric inputs per partition. An empty denominator gives tagged absence. Expose an exact ratio for a repeating decimal. Any rounded display needs a declared display precision and rounding rule in the measure and keeps the exact ratio in evidence. |
| Distinct count | Count distinct present typed values at the requested grain. Use canonical identities for references. Empty input gives zero. |

Partition every money measure by the currency supplied by the source contract (fixed canonical currency or a validated stored currency selection on that fact). Use the same key for grouped rows, totals, charts, prints, CSV and card drill-through. Make each partition visible even when the author omits Currency from the layout. Apply the same rule to incompatible quantity units. Reject incompatible partition bindings within one report, a missing currency on a monetary fact, malformed operands and precision overflow. Compare the provider output with a reference evaluator on signed, fractional, empty and boundary values. Compute totals from the full admitted fact set at its grain. Averaging group averages or adding group distinct counts would change the answer.

For day, Monday-based week and calendar month, use civil dates, converting instant sources via the tenant business zone and day boundary. Capture the business date and calendar once per run. Resolve the endpoints of **last month** independently through calendar boundaries. Age is the difference in civil days between the declared as-of business date and a due date. Proposed bands are **Not yet due**, **0–30**, **31–60**, **61–90**, **91+**, and **No due date**. Thus 90 belongs to exactly one band. Age classifies balances at the source’s own horizon. A request for last month’s outstanding balance requires a query supporting that historical horizon. Current balances alone can only answer current exposure. ## Who can read or export

Companies in one tenant/environment share the active report definition. Each run binds its own working company. The gateway resolves the trusted tenant, environment, principal, verified release/fence and permitted working company. The shell’s explicit company selection must be authorized. Derive ownership, customer, currency, revision and join keys from stored facts or their authoritative read models. Apply tenant/environment, company, parent, archive and live row policy **in the provider before grouping or counting**, on every participating input. Use tenant-shared sources only according to their declared ownership. A shared party link cannot admit another company’s invoices. Resolve effective field, classification, aggregate and export policy on every request, including filter, sort, currency, bucket, group, label, measure, join and drill-through dependencies. If a required binding is narrowed, withhold the dependent report in full and give a generic unavailable response. Omit it from discovery and cards. Denials, errors, CSV headers, chart legends and assistant evidence must also honor field narrowing. [ADR-0015](ADR-0015-legal-entity-business-dimension.md) · [ADR-0071](ADR-0071-read-decisions-are-live-per-request-writes-per-call.md)

Use one authorized read-only snapshot per request. Check the live policy epoch and serving fence before returning any bytes. Reauthorize each page, drill-through and export. A switch away and back changes the fence. A saved view, cursor, cached result or earlier approval confers no grant. Exports require both report read and the applicable export grant. Assemble the complete bounded output first. Commit a scoped audit receipt under current authority before handing bytes to transport. Bind the actual actor, scope, fence, report/measure revisions, canonical parameter digest, read horizon, output format, row counts and exact output digest. A failure to record the receipt withholds the file. The receipt records issuance, even if the network disconnects. A fresh download reauthorizes. Use the existing trust path or a scoped function for this append. Any new definer function fixes its search path to `pg_catalog, pg_temp`; grant the runtime only the necessary function execution. ## How a run is bounded

Proposed slice 1 ceilings per invocation are **10,000 input facts, 500 groups including currency partitions, 50 groups per page, 2 MiB serialized output and a 2-second database statement timeout**. Apply the stricter of platform, registered query, export and policy bounds. The grouped query declares input-work and output limits separately. Budget all statements and retries under a 5-second monotonic request deadline. Check capability, parameter types/sizes, requested limits and plan shape before execution. Allow at most four group keys and eight measures, and bound selected field widths at compilation. Slice 2 may traverse at most two declared links, with at most one line collection establishing the grain. A later joined plan must account for visited rows across every input and intermediate, including rows rejected by residual predicates.

Push the trusted ownership scope into the index range so another company’s volume cannot consume this company’s allowance. Use an indexed scope/range scan with a cap-plus-one candidate probe **before** expensive residual filters, grouping and distinct work. Apply authorization inside the query and release only complete authorized results. Count groups to their cap plus one before paging. A final SQL LIMIT on a grouped output would leave the input unbounded. On an exceeded scan, row, group, byte or time budget return **Narrow the filter** without counts, partial rows, totals or downloadable bytes. Omit hidden filter suggestions. Exercise the exact boundary and the next fact/group. A selective predicate over too many candidates must also refuse within budget.

At compile/prepare time list the required indexes and the reason for each. For a company-owned date-range report the candidate path needs equality on physical tenant/environment/company scope, then the stored date and stable record ID. A scoped primary-key range can serve a small whole-company report under the same candidate cap. A to-one lookup needs a scoped unique target key. Line traversal needs an ordered scope/parent/line key. Bucket after selecting the bounded date range. Derive keys from the storage mapping and verify actual index definitions and validity before activation. Build an index on a new managed table via its compiled storage transition. On an existing table use a proven bounded existing path or refuse with the missing keys until a verified online-build transition exists. Report execution cannot issue DDL. At launch-shaped cardinalities, observe the intended index actually used and the bounded work in PostgreSQL, including the probe with the index removed. [ADR-0011](ADR-0011-compiled-module-storage-transitions.md) · [ADR-0022](ADR-0022-query-level-aggregate-contract.md)

Order groups by a deterministic typed tuple with explicit absence order, collation and complete group/currency key as tie-breaker. Keyset pages seek strictly after that tuple. Each request recomputes the bounded complete authorized result in a fresh snapshot. Hash the ordered canonical keys, visible labels, cells and totals across all pages; keep the wall clock of the new request outside that comparison. Bind the opaque authenticated continuation to principal, tenant/environment/company, report revision, release/fence, policy epoch, filters, captured dates, order and digest of that complete result. On change, expiry or tampering require a fresh traversal. No transaction spans page requests. Totals accompany each page with their full scope labelled. CSV, chart and print consume the same complete bounded result or refuse. An export launched from a displayed result must detect a changed result and offer refresh before exporting it.

## How people use the result

The report opens as a deep-linkable grouped **List** in the owning module. Saved views are tabs with validated parameter presets and presentation choices. They can narrow the declared query. Desktop Customize provides the properties drawer, preview and publish diff. Compact renders group cards, currency-labelled totals and ordinary paging links. A chart has a labelled data table reachable with script off. A bar compares groups, a line needs an ordered dimension, and a stacked bar needs additive series with compatible units and currency. Separate currency panels prevent a visual combined total. CSV identifies group and total rows, quotes cells and neutralizes spreadsheet formula text while preserving signed typed numbers. A printable report includes company, customer filter where relevant, basis, horizon, currency, authorized detail and totals. Printable statement detail uses the declared invoice-grain drill-through under the same snapshot and budgets. An issued file uses the export authority and audit path. A DOCS-1 template may consume only these authorized bindings. [UX grammar](../../.agents/skills/ux-grammar/SKILL.md) · [ADR-0079](ADR-0079-form-and-record-composition.md)

A report-backed Today card binds a report ID, compatible revision, saved view/parameters, approved measure ID and partition selector. It reads the full report total under the viewer’s live grants. A multi-currency card shows labelled totals or asks for a currency if it requires a single number. Its link reopens the same report, company, parameters and period. A bound measure that changes meaning requires a new reviewed binding. Keep existing direct-List metric cards working. For “how much did we rent last month?”, the assistant discovers the declared basis, asks for clarification when several measures fit, then invokes `erp_query` with the report query ID and permitted time parameters. Show basis, company, exact window, currencies, freshness and a link to the same view. If a measure or historical source is missing, explain the capability gap. The typed gateway accepts no raw SQL or model-authored joins. [Plan §§9.2 and 10.2](../greenfield-north-star-erp-platform-plan.md)

## Admission, replay and build order

Propose a closed, versioned `addReportRevision` patch member with tenant-namespaced stable report ID, new revision ID, predecessor digest (absent only on creation), status and full effective definition. Rename or edit appends a successor. Retirement appends a tombstone and removes discovery and execution, including direct links. Prevent reuse of a retired ID. Propose separate versioned members for reusable measure revisions and report-card bindings when their slices ship. Each uses a stable ID and expected predecessor. A report may bind a reviewed measure from its own change set or a previously released one. Reject dangling dependencies unless their consumers are revised or retired in the same ordered change set. Preserve the original bytes and audit history. Preview the source, measures, grants needed, outputs, index plan and dependent changes. Verify the exact candidate, obtain human approval bound to its decision digest and current source fence, then activate by CAS. Compatible pointer rollback recovers the previous definitions under current grants.

Use optional nonempty v6 declarations. Bidirectionally verify declarations, compiled query/lowering, reporting metadata, all elected consumers and mandatory Surface reader floor. Exclude default keys, references, empty artifacts and new floors when declarations are absent. Against identical parents, reproduce a historical first-party lineage and a real tenant-customized lineage with no reports through production compile/persist/load. Read back and compare the revision’s stored `app_package_revisions.desired_state`, the full set of linked `release_artifact_blobs.canonical_bytes` (chunks and manifests), the reconstructed release envelopes, roots and floors byte for byte. For each newly incompatible capability, fetch main at executable merge and take its next free scalar rung. Recompute the maximum across *all* present features, regenerate and rerun CI on collision. Test the archived preceding **production loader** on persisted releases with and without the feature and test an understated manifest with the current verifier. Binary deployment respects every tenant’s highest used parser and reader even after pointer rollback. This design allocates no rung or migration. [ADR-0074](ADR-0074-formula-rule-and-workflow-projection-admission.md) · [ADR-0085](ADR-0085-platform-upgrades-for-customized-tenants.md)

Admit each new patch kind independently in the handwritten replay allowlist. Recursively check ordered change-set members. CI must name any vocabulary kind lacking admission. Reproduce original roots from retained bases and recorded inputs first. Exercise a compatible base addition and a real scoped conflict per kind, including a retired measure dependency or changed query grain. Preserve the verified source on refusal and identify the patch, stable subject and typed diagnostic. Do not repoint by label. If existing v6 meanings or required keys must change, return for a language ruling. A projection change for identical normalized input follows ADR-0047’s compiler-profile rule. [ADR-0085, replay admission](ADR-0085-platform-upgrades-for-customized-tenants.md#slice-1-replay-admission) · [ADR-0047](ADR-0047-the-compiler-semantic-profile-is-the-projection-evolution-axis.md)
